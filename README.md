# Lukas Steak Cooking Planner

A simple steak-cooking planner for braais and dinner service.

## What it does

This small web app lets you:

- add each guest and their steak preference
- choose a serving time
- generate a cooking plan that tells the chef when to:
  - put each steak on
  - flip it
  - take it off
  - serve it after resting

## How to use it

Open `index.html` in a browser, or serve the folder with a static file server.
